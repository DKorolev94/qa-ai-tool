## Длительность (Duration)

Проверь реалистичность duration для ручного выполнения.

Флажь `medium`, если:
- duration явно нереалистична. Пример: сложный E2E указан как `1 мин`, или простой атомарный кейс — `60 мин`.
- duration слишком мала для количества шагов и подготовки данных.
- duration не учитывает setup, подготовку данных или cleanup.

Флажь `low`, если duration немного неточная, но кейс понятен и выполним.

Не флажь, если:
- оценка спорная, но допустимая.
- в тесте есть ожидание внешних систем: email/SMS, очереди, cron. Это увеличивает время.
- duration относится к автотесту, а не к ручному выполнению.

Ориентиры для ручного выполнения:
- атомарный UI-кейс без подготовки данных: 2–5 мин
- стандартный UI-кейс с тестовыми данными: 5–15 мин
- E2E, интеграционный, API или DB кейс: 15–30 мин

## Как исправлять

Скорректируй значение `duration` в миллисекундах на основе количества шагов и сложности теста:
- Атомарный UI-кейс без подготовки данных: 120000–300000 мс (2–5 мин)
- Стандартный UI-кейс с тестовыми данными: 300000–900000 мс (5–15 мин)
- E2E, интеграционный, API или DB кейс: 900000–1800000 мс (15–30 мин)
