## Связь с требованиями (Requirement Traceability)

Флажь `high`, если:
- тест явно противоречит указанному требованию.
- expected result несовместим с описанием задачи или user story.

Флажь `medium`, если:
- поле `links` / `references` пустое И по title, description и steps невозможно понять, какое требование или функциональность покрывается.
- источник указан слишком общо. Примеры: `по требованиям`, `по задаче`. Нет ID или ссылки.

Не флажь, если:
- тест exploratory и это указано.
- тест создан по известному баг-репорту.
- ссылка есть в title, description, tags или references.
- по title, description и steps однозначно ясно, какой сценарий покрывается. Пустое поле `links` само по себе не является нарушением.

## Как исправлять

Поле `links` нельзя заполнить без знания требований и задач. Пометь `manual_needed`: «Добавь в поле links ссылки на требования, user story, задачу или баг-репорт, который покрывает этот тест-кейс.»
